# エディタ設定取得 API 仕様書兼設計書

[← API一覧](README.md)

| 項目 | 内容 |
| --- | --- |
| API名称(論理名) | エディタ設定取得 |
| API名称(物理名) | EditorSetting (GET) |
| API名称(リクエストパス) | `/api/editor/setting` |
| HTTPメソッド | GET |
| リクエスト形式 | - |
| レスポンス形式 | `application/json` |
| 認証可否 | 必要 |
| ステータスコード | 200: 取得に成功した場合 (未設定でも 200)<br>401: 未ログインの場合 |
| 備考, 概要 | エディタを開いたときに、前回選んだ背景画像のスロット番号を復元するために使う |

## 入力値

なし

## 戻り値

| 論理名 | キー名(物理名) | 型情報 | 省略可否 | 備考, コード値等 |
| --- | --- | --- | --- | --- |
| 選択中の背景スロット番号 | selectedSlotNumber | number / null | 省略不可 | 1〜4。未選択の場合は `null` |

選択中のスロットが未選択・削除済みの場合、画面はスロット1を使い、背景画像が0枚の場合はサンプルのサロン風画像を使う。

## 内部ロジック

### 処理フロー

1. ログインユーザーを取得する (未ログインは 401)
2. ログインユーザーのエディタ設定を取得する。無い場合は `null` を返す

### 参照先DB一覧

- [エディタ設定 (editor_setting)](../db/09-editor-setting.md)

### 対象レコード取得条件

- `editor_setting.userId` = ログインユーザーID

- `src/app/api/editor/setting/route.ts` (GET)
- `src/types/api/editor/setting/index.d.ts`
