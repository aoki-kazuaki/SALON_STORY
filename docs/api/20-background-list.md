## 内部ロジック

### 処理フロー

1. ログインユーザーを取得する (未ログインは 401)
2. ログインユーザーの背景画像スロットを、スロット番号 1〜4 の範囲でスロット番号の昇順に取得する
3. スロットごとに表示用の署名付きURLを発行して返す

### 補足 (署名付きURLとキャッシュ)

- 署名日時を3日単位の区間の開始にそろえるため、同じ区間内は毎回同じURLになる (ブラウザのキャッシュが効き、S3 への再ダウンロードが発生しない)
- URLの有効期限は6日 (区間の最後に発行しても最低3日は有効)
- 画像レスポンスに `Cache-Control: private, max-age=259200, immutable` (3日) を付ける
- 画像はアップロードのたびに新しいオブジェクトキーで保存するため、同じURLの内容が変わることはない
- スロット数を5→4に減らした経緯から、5番以上の旧データは返さない (選択中だった場合、エディタはスロット1にフォールバックする)
