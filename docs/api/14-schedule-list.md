# スケジュールメモ一覧取得 API 仕様書兼設計書

[← API一覧](README.md)

| 項目 | 内容 |
| --- | --- |
| API名称(論理名) | スケジュールメモ一覧取得 |
| API名称(物理名) | ScheduleList |
| API名称(リクエストパス) | `/api/schedule/list` |
| HTTPメソッド | GET |
| リクエスト形式 | クエリパラメータ |
| レスポンス形式 | `application/json` |
| 認証可否 | 必要 |
| ステータスコード | 200: 取得に成功した場合 (該当0件でも 200)<br>400: 日付の形式が不正な場合<br>401: 未ログインの場合 |
| 備考, 概要 | 月別一覧 (当月1日〜末日)・ストーリーズエディタ (月指定・期間指定)・メモ入力ダイアログ (選んだ日付の登録済みメモの読み込み。開始日＝終了日) で使う。<br>エディタは同じ期間を取得済みであれば再取得しない (差分比較による通信抑制) |

## 入力値

| 論理名 | キー名(物理名) | 型情報 | 省略可否 | 備考, コード値等 |
| --- | --- | --- | --- | --- |
| 取得開始日 | startDate | string | 必須 | 日付キー (`YYYY-MM-DD`)。実在する日付のみ |
| 取得終了日 | endDate | string | 必須 | 日付キー (`YYYY-MM-DD`)。この日を含む |

## 戻り値

| 論理名 | キー名(物理名) | 型情報 | 省略可否 | 備考, コード値等 |
| --- | --- | --- | --- | --- |
| 検索結果 | memos: [ | 配列 (始) | 省略不可 | 日付の昇順。該当なしは `[]` |
| 　メモID | id | string | 省略不可 | |
| 　対象日 | dateKey | string | 省略不可 | 日付キー |
| 　メモ本文 | content | string | 省略不可 | 改行を含む (最大5行) |
| 　最終更新日時 | updatedAt | string | 省略不可 | ISO 日時 |
| - | ] | 配列 (終) | - | |

## 内部ロジック

### 処理フロー

1. ログインユーザーを取得する (未ログインは 401)
2. クエリパラメータを検証する
3. ログインユーザーのメモのうち、期間内かつ本文が空でないものを日付の昇順で取得する

### 例外処理

| ステータス | code | 条件 |
| --- | --- | --- |
| 400 | `BAD_REQUEST` | `startDate` / `endDate` が無い、形式不正、存在しない日付 |
| 401 | `UNAUTHORIZED` | 未ログイン |

### 参照先DB一覧

- [スケジュールメモ (schedule_memo)](../db/06-schedule-memo.md)

### 対象レコード取得条件

- `schedule_memo.userId` = ログインユーザーID
- `schedule_memo.date` ≧ 入力項目.取得開始日 かつ ≦ 入力項目.取得終了日
- `schedule_memo.content` ≠ `""` (クリア済みの日は含めない)
- 並び順: `date` 昇順
