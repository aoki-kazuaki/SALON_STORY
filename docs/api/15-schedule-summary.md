## 内部ロジック

### 処理フロー

1. ログインユーザーを取得する (未ログインは 401)
2. ログインユーザーの本文が空でないメモの日付を全件取得する
3. 年・月ごとに件数を集計し、年の降順・月の降順に並べて返す

### 例外処理

| ステータス | code | 条件 |
| --- | --- | --- |
| 401 | `UNAUTHORIZED` | 未ログイン |
